# tok_wiki

`index.html` の1ページに、41種類・2,340個のピンと、地名チェック223か所をまとめて載せている。地図は空島・地上・地底の3つ。

## 使い方

- 地図の下のメニューで、種類ごとにピンの表示を切り替える。初めて開いたときは祠と鳥望台だけが出ている。どれを出しているかはそのブラウザに覚えておき、次に開いたときも同じになる
- 閉じたメニューには2段見える。上の段はお気に入り（どの地図でも同じ）、下の段は地図に合わせた段で、空島・地上では地上の段、地底では地底の段（地底の根・深穴・樹海など）が出る。お気に入りに何も置いていない間は、下の段だけが見える
- 下の段の左端の「表示設定」を押すと上に開き、すべての種類が横7マスのマス目に並ぶ（見出しは無く、細い線で区切っている）。地図を触ると閉じる
- 「全てOFF」は、開いたときの「表示設定」の段のすぐ下の段の左端にある。地底で段が入れ替わっても、この場所は変わらない
- 下メニューの並びは、☰ →「下メニューの並べ替え」で変えられる。1段目がお気に入り、2段目が地上の段、3段目が地底の段（背景の色で分けている）。アイコンを指で動かし（空きマスへは移動、他のアイコンの上では入れ替え）、段と段の間を押すと区切りの線を付け外しできる。「表示設定」（2段目の左端）と「全てOFF」（3段目の左端）は動かせない。保存すると GitHub に保存され、どの端末でも同じ並びになる（トークン未設定のときはそのブラウザだけ）
- チェック済みのピンは、少し透けて、右上に小さな赤丸が付く
- メモの横の目のボタンを押すと、チェック済みのピンを全種類まとめてもっと薄くする（赤丸はそのまま。もう一度押すと戻す。どちらにしているかはそのブラウザに覚えておく）
- 夜光イワロックは、ふつうのイワロックと見分けられるよう青緑に光らせている
- 「地名」をONにすると、地名ごとにチェックの印が出る（地図を大きく拡大したときだけ）。印を押すとチェックが付く
- 「影の像」のボタン（両手剣のアイコン）1つで、片手剣・両手剣・槍の影の像をまとめてON/OFFする。ONにすると、検索欄のすぐ上に武器名のプルダウンが出る。武器を選ぶと、その武器が出る影の像だけが残る
- 大きく拡大すると、ボスなどの名前が地図に文字で出る
- 地図は画面いっぱいに出る（上部バーは無い）
- 拡大縮小・☰（メニュー）・メモ・検索欄などの操作部品は、指が届きやすいよう地図の下側（メニューのすぐ上）に集めている。境界線（有／無）は進捗（n/152）の上に小さく置いている
- 地図の中心は画面の上から25%の位置として扱う。引いた地図でも、地図の下の方を画面の真ん中まで持ち上げて見られる。＋−ボタンは上から25%の点を中心に拡大縮小する
- 今の地図にピンが無い種類をONにすると、どの地図にあるかを知らせる（賢者の遺志・古びた地図は空島にだけある）
- ☰ の下の鉛筆のボタンを押すと、メモが画面の下半分に出る（上の地図はそのまま使える。編集中は画面いっぱい）。「編集」で書き換え、「保存」で GitHub に保存する（どの端末でも同じメモになる。トークン未設定のときはそのブラウザだけ）。書いた文字は空白や改行も含めてそのまま保存・表示される
- 検索欄から、名前でピンを探せる。押すと、検索欄のすぐ上に入力欄が出て、その上に候補の一覧が並ぶ。対象は祠・祠チャレ・鳥望台・洞窟・井戸・施設・馬宿・神殿・地底の根・大妖精の泉・地上絵・廃鉱・製錬ゴーレム・樹海・ゾナウギア製造機（ギアの名前で探せる）。選ぶと地図がその場所へ移り、その種類の表示もONになる
- ☰ を押すとサイドメニューが開き、種類ごとの進捗（チェック数／総数）が出る。施設・神殿・岩オクタ・ゾナウギア製造機・影の像など、チェック欄が無い種類は出ない
- サイドメニューの一番下の「すべてのチェックを消す」で、すべてのチェックを消せる（地名のチェックも消える。確認あり。元に戻すボタンは無い）

## ピンについて

- 洞窟・井戸だけ元サイトが Game8 で、地図の仕組みが別物のため、ピンのデータ（名前・位置・入口の画像・攻略記事リンク）を GameWith の地図ツールに載せ替えている。位置は両サイトに共通する祠・鳥望台から求めた式で変換した。入口が複数ある洞窟は「ボネ湖東の洞窟（1）」のように番号を付け、元ページと同じく入口ごとにチェックする
- 元の祠マップにあった「祠のある洞窟」のピン（31個）は載せていない。洞窟のピンと名前が同じものがあり、地図ツールが同じ名前の洞窟を1つのチェックにまとめてしまうため
- ボスのページには祠・鳥望台・洞窟・女神像のピンもあるが、ボス・岩オクタ・地底の根・深穴だけを取っている。洞窟は Game8 のデータを載せているので、同じ洞窟が2つにならないようにしている
- 深穴は、地上の入口と地底の出口が同じ名前で1つずつある（36か所×2）。チェックは別々に付く
- 完璧版（ハイラルマップ検索）からは、今まで載せていなかった種類と地名チェックだけを足した。今までのピンは id が変わらないので、今までのチェックはそのまま使える
- 完璧版にある洞窟・井戸は載せていない（今の Game8 由来とは id が違い、載せ替えると今までのチェックが外れるため）。防具の入手場所も、地図ツールが対応していない種類なので載せていない

## チェックデータの保存

チェック状態は GitHub 上の json に保存する。どのブラウザ・端末で開いても同じ状態になる。

- 保存先: `dancerksk307/dancerksk307.github.io` の `save-data` ブランチ、`tok_wiki/data/save.json`（`config.js` で変更できる）
- 最後のチェックから約3秒後に、その間の変更をまとめて1コミットで保存する
- すべての種類のチェック（地名チェックも含む）が同じ1つのファイルに入る
- 下メニューの並びは、同じブランチの別のファイル `tok_wiki/data/menu-layout.json` に保存する（チェックのファイルには触れない）
- メモは、同じブランチの別のファイル `tok_wiki/data/memo.txt` に、書いたとおりの文字のまま保存する（チェックのファイルには触れない）
- 保存状態は ☰ →「保存設定」の「状態」に出る（「保存済み」「未保存の変更あり」など）

公開用の master ではなく `save-data` ブランチに保存しているのは、master に保存するとチェックのたびに GitHub Pages の再公開が走り、履歴も保存コミットで埋まるため。ブランチは初回の保存時に自動で作られる。

## 初回の準備

1. このフォルダを `dancerksk307.github.io` リポジトリの `tok_wiki/` として push する
2. GitHub で保存用のトークンを作る
   - GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
   - Repository access: 「Only select repositories」で `dancerksk307.github.io` だけを選ぶ
   - Permissions → Repository permissions → **Contents: Read and write**（これだけ）
3. 地図ページを開き、☰ →「保存設定」にトークンを貼って「設定」を押す（ブラウザごとに1回）

トークンを設定していない間は、チェックはそのブラウザの中にだけ残り、設定した時点でまとめて保存される。

### トークンの扱い

- トークンはコードやリポジトリに書かない。入力したブラウザの中にだけ保存される
- 地図ページは外部サイト（GameWith・cdnjs）のプログラムを読み込んでいるため、権限は上記の最小限にする
- 漏れた疑いがあれば、GitHub の同じ画面でトークンを削除して作り直す

## ホーム画面に追加する（アプリとして使う）

スマホのホーム画面にアイコンを置き、アドレスバーの無い画面で開ける（PWA）。地図に使える高さが増える。

- Android（Chrome）: 地図ページを開き、右上の︙ →「ホーム画面に追加」（または「アプリをインストール」）
- iPhone（Safari）: 地図ページを開き、共有ボタン →「ホーム画面に追加」

注意

- 圏外では使えない。地図ツール・地図画像は毎回ネットから読み込む
- iPhone は、ホーム画面のアプリと Safari で保存場所が別になる。アプリ側でも ☰ →「保存設定」でトークンを設定し直す。チェックは GitHub 経由で共通になる（実機では未確認）
- 中身を更新したときは、アプリを開き直すと新しい内容になる
